# Westwood Font Editor

Westwood Font Editor is an editor specifically designed for editing indexed bitmap fonts. It can edit fonts from a very wide variety of games, though the majority of supported types are those from the games developed by Westwood Studios and Sierra/Dynamix.

Due to the fact the entire editor is built on manipulating 8-bit images, there is no support planned for Westwood's later high-colour font formats.
